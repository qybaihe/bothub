# BotHub

### **Соберите всех своих персональных агентов и пользуйтесь ими в одном клиенте — как в Grok Bot**

**Приложение для macOS и Windows, которое собирает ваших ботов Meta Muse, Grok Bot, Hark и Dot в одном окне; каждый бот работает под своим изолированным аккаунтом.**

## ⚡ Быстрый старт

Скачайте файл для своей системы из [последней версии](https://github.com/qybaihe/bothub/releases/latest):

| Система | Файл |
| :--- | :--- |
| macOS, Apple Silicon | `BotHub-<версия>-arm64.dmg` |
| macOS, Intel | `BotHub-<версия>-x64.dmg` |
| Windows 10/11 (x64) | `BotHub-Setup-<версия>-x64.exe` |

> [!TIP]
> Сборки пока не подписаны.
> - **macOS**: перетащите `BotHub.app` в «Программы», а при первом запуске щёлкните правой кнопкой и выберите **Открыть** (или *Системные настройки → Конфиденциальность и безопасность → Всё равно открыть*). Можно также снять атрибут карантина командой `xattr -cr /Applications/BotHub.app`.
> - **Windows**: если SmartScreen пишет «Система Windows защитила ваш компьютер», нажмите **Подробнее → Выполнить в любом случае**.

Затем нажмите **+** на боковой панели, выберите платформу и войдите. У каждого бота свой аккаунт.

**Обновления**: в Windows BotHub скачивает новые версии в фоне и устанавливает их одним щелчком. В macOS он сообщает о выходе новой версии и открывает страницу загрузки.

## 🤖 Поддерживаемые платформы

| Платформа | Протокол и транспорт | Возможности |
| :--- | :--- | :--- |
| **Meta Muse** (`muse.ai`) | Изолированный раздел Electron + нативный шлюз WebSocket | Несколько аккаунтов, пакетный импорт с кодами из почты, HTTP/SOCKS5-прокси для каждого аккаунта, облачный компьютер, цели, пиры, файлы рабочего пространства, одобрение коннекторов и диагностика |
| **Grok Bot** (`grok.com`) | Connect-RPC / Protobuf через шлюз Sand (`*.sand.x.ai`) | Несколько аккаунтов, облачное рабочее пространство Sand, потоковый вывод, история вызовов инструментов, сессии, запланированные задачи, память и навыки |
| **Hark** (`hark.com`) | WebSocket RPC + мультимодальный REST | Вход через браузер (Google или почта), потоковый вывод с фоновой синхронизацией ответов, вложения файлов и изображений, карточки документов, запланированные задачи, память и коннекторы |
| **Dot** (`chatgpt.com/dots`) | REST OpenAI Orbit/TBO + события от сервера (SSE) | Вход через OAuth в браузере или импорт Access/Refresh Token, зашифрованное хранение токенов, потоковый вывод, загрузка файлов, навыки, автоматизации, коннекторы и прокси для каждого аккаунта |

## ✨ Возможности

- **Много аккаунтов без путаницы**: каждый аккаунт работает в своём разделе Electron `persist:` или в зашифрованной ячейке учётных данных, так что можно одновременно пользоваться несколькими аккаунтами одной платформы.
- **Консоль управления**: полноэкранный режим с общей сводкой, фильтром и поиском ботов, пакетной проверкой подключения, а также аккаунтами, токенами и прокси для каждой платформы.
- **Полноценный чат с агентами**: потоковый вывод с ходом рассуждений и карточками инструментов, восстановление долгих фоновых задач, таблицы Markdown, подсветка кода, предпросмотр документов и скачивание вложений.
- **Панель сведений о боте**: правая панель показывает сессии, запланированные задачи, память, навыки, файлы и участников бота — в зависимости от платформы.
- **Живые аватары**: у каждого бота есть анимированный персонаж `GrokBotMark`, который следит за курсором и реагирует во время работы; можно выбрать форму и цвет или загрузить фото.
- **Безопасность по умолчанию**: токены и пароли прокси шифруются через `safeStorage` в Electron (Связка ключей в macOS) и сохраняются с правами `0600`. Никаких секретов в коде и никакой телеметрии.
- **Интерфейс на английском и китайском**, светлая и тёмная темы.

## 🧰 Разработка

```bash
npm ci
npm run dev          # Electron + Vite с горячей перезагрузкой
```

| Команда | Описание |
| :--- | :--- |
| `npm run dev` | Запускает главный процесс Electron, preload и интерфейс на React с горячей перезагрузкой |
| `npm run dev:web` | Запускает только интерфейс в браузере (без Electron и без аккаунтов) |
| `npm run typecheck` | Проверяет типы для Node и веба |
| `npm test` | Модульные тесты (Vitest) |
| `npm run build` | Проверяет типы и собирает продакшен-сборку в `out/` |
| `npm run dist:mac` / `npm run dist:win` | Упаковывает macOS `dmg` + `zip` (arm64 + x64) / установщик Windows NSIS в `release/` |
| `npm run dist:dir` | Неупакованное приложение macOS arm64 для быстрой проверки |

Снимок экрана для README создаётся на вымышленных данных: `npx -y -p playwright@1.64 node scripts/screenshot/capture.mjs [--dark]`.

## 🚀 Выпуск версий

При каждом push CI ([`ci.yml`](../../.github/workflows/ci.yml)) проверяет типы, запускает тесты, собирает и упаковывает приложение в macOS и Windows.

1. Повысьте `version` в `package.json` и слейте изменения в `main`.
2. Отправьте тег `vX.Y.Z`, совпадающий с версией.
3. [`release.yml`](../../.github/workflows/release.yml) создаёт черновик релиза, собирает macOS (arm64 + x64 `dmg`/`zip`, `latest-mac.yml`) и Windows (NSIS `exe`, `latest.yml`), загружает всё и публикует релиз, когда все файлы на месте.

По умолчанию сборки не подписываются. Подпись и нотаризация включаются, если заданы секреты репозитория: `CSC_LINK`, `CSC_KEY_PASSWORD`, `APPLE_ID`, `APPLE_APP_SPECIFIC_PASSWORD`, `APPLE_TEAM_ID` (macOS) или `WIN_CSC_LINK`, `WIN_CSC_KEY_PASSWORD` (Windows).

## 📁 Структура проекта

```text
src/
  adapters/        Адаптеры платформ (Meta Muse, Grok Bot, Hark, Dot) и общий интерфейс PlatformAdapter
  main/            Главный процесс Electron
    muse/          Сессии Muse в разделах, пакетный вход и прокси для каждого аккаунта
    muse-native/   Клиент нативного шлюза WebSocket для облачного компьютера и рабочего пространства Muse
    grok/          Аутентификация Sand, клиент Connect-RPC и обработчики IPC для Grok Bot
    hark/          Клиент WebSocket/REST, загрузка вложений и обработчики IPC для Hark
    dot/           Клиент OpenAI Dot (Orbit/TBO), зашифрованное хранилище токенов, потоковый SSE и IPC
  preload/         Типизированный API contextBridge, доступный как window.electron
  shared/          Контракты каналов IPC и типы, общие для главного процесса и интерфейса
  renderer/        Настольный интерфейс на React + Tailwind + Zustand
    components/    Боковая панель, чат, панель сведений, панели платформ, консоль управления, GrokBotMark
    store/         Состояние ботов, сведение потоковых сообщений и сохранение данных
scripts/screenshot/  Снимок экрана для README на вымышленных данных
```

## 📚 Документация по протоколам

- **OpenAI Dot** (`chatgpt.com/dots`): [`docs/dot/protocol.md`](../dot/protocol.md): OAuth PKCE и аутентификация веб-сессии, профили Orbit, SSE и REST для комнат, WebSocket JSON-RPC 2.0, Pages, библиотека и перенос памяти

- **Hark** (`hark.com`): [`docs/hark/protocol.md`](../hark/protocol.md): эндпоинты REST и потоковый NDJSON, коннекторы, запланированные задачи, дерево файлов ВМ и сессии компьютера

## ❓ Вопросы и ответы

<details>
<summary><b>BotHub — официальное приложение этих платформ?</b></summary>

Нет. BotHub — независимый клиент, не связанный с Meta, xAI, Hark или OpenAI. Он использует ваши собственные аккаунты на каждой платформе.

</details>

<details>
<summary><b>Где хранятся мои аккаунты и токены?</b></summary>

Только на вашем компьютере. Веб-сессии хранятся в отдельных разделах Electron для каждого аккаунта; токены и пароли прокси шифруются через `safeStorage` (Связка ключей в macOS) и сохраняются с правами `0600`. BotHub не отправляет телеметрию.

</details>

<details>
<summary><b>macOS сообщает, что BotHub нельзя открыть. Что делать?</b></summary>

Сборки пока не подписаны. Щёлкните по приложению правой кнопкой и выберите **Открыть** или выполните `xattr -cr /Applications/BotHub.app`. Подробнее — в разделе [Быстрый старт](#-быстрый-старт).

</details>

<details>
<summary><b>Сообщение долго висит в статусе «доставлено · отвечает». Повторная попытка отправит его дважды?</b></summary>

Нет. Если платформа приняла сообщение, BotHub никогда не покажет его как неотправленное. Если ответа нет, появится статус *нет ответа* и кнопка **Отправить ещё раз**, по которой явно понятно, что будет отправлена вторая копия.

</details>

<details>
<summary><b>Можно ли для каждого аккаунта задать свой прокси?</b></summary>

Да, для аккаунтов Muse и Dot (HTTP или SOCKS5). Если прокси применить не удаётся, BotHub блокирует трафик этого аккаунта, а не переходит на прямое подключение.

</details>
